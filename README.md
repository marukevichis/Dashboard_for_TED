# Дашборд для компании, организующей первую конференцию TED по лицензии

Аналитическому агентству поручено создать дашборд для организатора первой конференции формата TED. Задача заключается в изучении опыта предыдущих мероприятий и разработке инструмента, помогающего обеспечить успех нового события.

Задача заказчика состоит в следующем:

- определить популярные темы выступлений и реакцию зрителей;
- выяснить оптимальное количество спикеров и продолжительность докладов;
- найти интересных выступающих и успешные форматы презентаций.

## Дашборд содержит следующую информацию:

**1. Верхнеуровневые метрики, которые отражают общие данные по конференциям и потенциальные объемы будущих аналогичных конференций:**
- количество мероприятий (учитываются все конференции, включая те, где не было выступлений);
- число выступлений (общий подсчет всех презентаций);
- уникальные спикеры (число уникальных выступающих);
- разнообразие тем (количество используемых тем или тегов).
  
**2.Детализация по странам и конференциям:**
- средняя длительность выступления;
- максимальное количество просмотров, которое было у выступления;
- сколько раз аплодировали за всю конференцию;
- количество выступающих.
  
**3. Формирование информации наиболее популярных выступлений, в том числе отражение следующих показателей:**
- топ-10 самых смешных выступлений,
- топ-20 самых популярных тегов.
  
**4. Формирование профиля выступающих**

### Фильтры и навигация:

Пользователь сможет быстро ориентироваться благодаря удобным инструментам фильтрации:
- поиск по стране;
- выбор конкретной конференции;
- отбор выступлений по ключевым словам;
- временные фильтры по дате записи выступления.

При построении дашборда использовались 3 таблицы с данными: `events`, `speakers` и `talks.`

Таблица `events` содержит информацию о конференциях:

- `conf_id` — идентификатор конференции. Первичный ключ таблицы;
- `event_name` — название конференции;
- `country` — страна проведения конференции.

Таблица `speakers` – информация о выступающих на конференциях спикерах: 
- `author_id` — идентификатор выступающего. Первичный ключ таблицы;
- `speaker_name` — имя выступающего;
- `speaker_occupation` — род деятельности выступающего;
- `speaker_description` — краткое описание выступающего.

Таблица `talks`  содержит информацию о выступлениях:

- `talk_id` — идентификатор выступления. Первичный ключ таблицы;
- `url` — интернет-ресурс, где выступление находится в открытом доступе;
- `title` — название выступления;
- `description` — краткое описание выступления;
- `film_date` — дата видеозаписи выступления;
- `duration` — длительность выступления;
- `views_count` — количество просмотров выступления;
- `main_tag` — основной тег выступления;
- `speaker_id` — идентификатор выступающего. Внешний ключ, который связан со столбцом author_id таблицы speakers;
- `laughter_count` — число случаев, когда в зале звучал смех;
- `applause_count` — число случаев, когда в зале звучали аплодисменты;
- `language_sp` — язык, на котором велось выступление;
- `event_id` — идентификатор конференции. Внешний ключ, который связан со столбцом conf_id таблицы events.

Дашборд позволит эффективно анализировать аудиторию и содержание прошлых мероприятий, помогая создавать привлекательные и эффективные презентации на будущих конференциях.
